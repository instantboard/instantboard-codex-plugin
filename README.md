# Instantboard for Codex

![Instantboard](plugins/instantboard/assets/logo.svg)

Remote [MCP](https://modelcontextprotocol.io) server for [Instantboard](https://instantboard.app) — manage cards and columns from Codex.

## Install

```bash
codex plugin marketplace add instantboard/instantboard-codex-plugin
codex plugin add instantboard@instantboard
```

Complete Instantboard OAuth when Codex prompts you.

Server URL: `https://instantboard.app/mcp`
